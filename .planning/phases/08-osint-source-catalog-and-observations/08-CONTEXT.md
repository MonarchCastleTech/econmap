# Phase 8 Context

## Goal

Expose what each OSINT layer can and cannot establish. A sparse source miss must never become a
negative fact about a city.

## Decisions

- Published operational layers carry source URLs, scope, join method, fields, a default state,
  and a gap reason.
- Place-of-worship observations are cataloged from OpenStreetMap and Overture Places.
- Generic mobile performance does not establish 5G coverage.
- Technology-specific 5G remains `unknown` without operator, regulator, or tagged observations.
